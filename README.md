# yarakazem.github.io

Design portfolio, live at **https://yarakazem.github.io**.

Plain HTML and JS styled with [Tailwind CSS v4](https://tailwindcss.com). Push to `main` and a GitHub Action builds the CSS and deploys to Pages.

## Structure

```
index.html            Home: hero, work grid, about, contact
src/input.css         Tailwind entry: design tokens + site styles (edit this)
styles.css            Generated by Tailwind, not committed
script.js             Footer year + scroll reveal
work/                 One HTML page per case study
assets/img/           Images for thumbnails and case studies
```

## Adding a case study

1. Copy `work/_template.html` to `work/<project-name>.html` and fill it in.
2. Turn its `<article class="card">` into an `<a class="card" href="work/<project-name>.html">` in the `#work` grid in `index.html`.
3. Put images in `assets/img/` and swap the placeholder `.thumb` gradient for an `<img>`.

## Styling

Use Tailwind utility classes directly in the HTML. The site's tokens are available as utilities:
`bg-bg`, `bg-surface`, `text-text`, `text-muted`, `border-line`, `text-accent`, `font-serif`, `font-sans`, `rounded-card`.
Change the token values in `src/input.css` (light and dark mode).

## Local preview

```bash
npm install
npm run dev     # rebuilds styles.css on every change
npm run serve   # in a second terminal, then open http://localhost:8000
```
